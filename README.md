# Hiring Desk (Android)
Offline CV screening app. The whole app is app/src/main/assets/index.html shown in a WebView; there is no INTERNET permission.
Push to main -> GitHub Actions builds HiringDesk-N.apk and HiringDesk-N-debug.apk -> open Releases to download.
Update the app: replace app/src/main/assets/index.html and commit.
